로마노프 초능력 영어

생활영어 100문장 · 모바일 최적화

사용법

  1. 단어장에 생활영어 100문장이 미리 저장되어 있습니다.
  2. 각 문장에 알파벳 스토리가 연결되어 있습니다.
  3. 하단 복습 탭에서 플래시카드로 바로 학습하세요.
  4. 카드를 탭하면 뒤집힙니다 (영어 ↔ 뜻+스토리).
  5. 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

홈 화면에 추가하는 방법

iPhone: 공유 버튼 → “홈 화면에 추가”
Android: 메뉴(⋮) → “홈 화면에 추가” 또는 “앱 설치”
